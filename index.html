Personal Projects

screenshot: tax-code-graph.png
Tax Code Graph
Python

The U.S. Harmonized Tariff Schedule is the official list of taxes on imported goods: the product chapters name what is being imported, and the temporary-duty overlay says how it is taxed right now. A temporary duty reduction usually replaces the normal tax (often making it free); a temporary duty increase usually adds extra tax, often by country of origin. I built a heading-card app that shows one of those rules at a time, with the connections stored as a graph over a saved copy of the official schedule.

  • Four independent Hatchet scrape tasks so a PDF timeout does not wipe JSON that already landed. Writes go through a temp file and Path.replace(); provenance is recorded, and re-runs overwrite in place instead of duplicating.
  • The overlay is a graph, not a table of strings: rules store rate_kind + rate_value so “MFN + 25” is expressible, and edges capture references (overlay → product) and exclusions (overlay → overlay) without treating citations as foreign keys.
  • Regex over heading prose extracts provided-for citations, exclusion spans, and rate operators, prefix-matching 8-digit codes onto 10-digit lines without exploding short headings into thousands of children. PDF notes join a heading only when citation, subdivision, and heading number all appear in the body.
  • The app is a heading card over a materialized view — homepage teaches duty reduction vs duty increase — and never re-fetches. It reads the snapshot Parse loaded, including which USITC revision.
  • Rates are expressions, not display strings (free → 0, additive → base MFN + N). Annex tables still pollute note counts, and origin stacking is out of scope.
Hatchet PostgreSQL TypeScript Docker Bun ETL PDF Extraction Domain Modeling

CapVid
SwiftUI

A macOS app for adding captions to videos — transcribe speech, clean up the results, style the text, and export a captioned video plus a separate caption file.

  • End-to-end pipeline design: video import → on-device speech transcription → editable caption review → font/size styling → dual export (burned-in video + standalone caption file)
  • CaptionTimeline sanitization engine corrects noisy ML output: overlapping segments, timestamps past playable duration, end-of-timeline pile-up, and unreadably short captions via bounded iterative overlap resolution with configurable tolerances
  • Composition-duration logic reconciles asset, video-track, and audio-track lengths into one safe export timeline, preventing caption/media desync
  • Library/app split: testable core package isolated from UI, with unit-tested interval logic via swift build and swift test; demo UI ships the sanitization foundation while import, transcription, and export are in active development
